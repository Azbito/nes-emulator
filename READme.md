A CPU6502 emulator developed in C++ and using SDL3 for rendering ROM sprites.
CPU6502 can run the following systems:

- NES
- Nintendo Game Boy
- Atari 2600
- Atari 7800
- Commodore 64
- Apple II
- BBC Micro

## Dependencies

- Allegro5
